# 룰루랜드 — 탕후루 먹방 픽셀 게임

모바일 게임 「탕후루의 달인」(Tanghulu Master)의 **룰루랜드**에서 캐릭터와 놀이 콘셉트를 빌려 온 팬 창작 픽셀 게임입니다.
그림은 모두 코드 안의 픽셀 문자열로 새로 그렸고, 외부 이미지는 쓰지 않습니다.

`index.html` 하나만 브라우저로 열면 바로 할 수 있어요. 글꼴과 three.js까지 들어 있어 인터넷 없이도 3D로 돕니다 (약 870KB).

## 화면

### HD-2D 3D 무대 (three.js)

타이틀, 룰루랜드 거리, 탕후루 가게는 [three.js](https://threejs.org/)(r128)로 그린 3D 무대 위에서 펼쳐집니다. 룰루와 손님, 고양이는 원래의 픽셀 그림을 3D 공간에 세운 판으로 두어(옥토패스 트래블러 같은 HD-2D 방식) 빛과 그림자를 받습니다.

- **거리**: 가게 건물·차양·픽셀 글꼴 간판, 돌아가는 관람차와 불빛, 오르내리는 드롭타워, 물줄기가 솟는 분수, 가로등과 가랜드, 낮은 다각형 나무, 멀리 보이는 성과 언덕, 흘러가는 구름. 해 그림자가 캐릭터 모양대로 떨어지고, 가게를 누르면 3D 광선으로 골라 걸어갑니다.
- **탕후루 가게**: 딸기·청포도·귤·블루베리·키위·마시멜로·젤리곰·고추를 3D 모형으로 만들고, 설탕 코팅은 빛이 비치는 유리 껍질(품질마다 투명·호박색·뿌연·갈색)로 씌웁니다. 끓는 시럽 냄비에는 기포와 김, 불꽃이 있고, 벽에는 창문·사탕 병 선반·전구 줄이 있습니다. 채팅·온도계 같은 2D UI 배치와 3D 물체의 위치가 정확히 맞도록 카메라 기울기를 계산해 맞춥니다.
- **후처리**: 틸트시프트 피사계 심도(먼 곳과 가까운 곳을 흐리게), 빛 번짐(블룸), ACES 톤 매핑, 채도·대비 보정, 비네트.
- 아이스크림 뽑기·드롭타워·옷장은 오락실 화면처럼 2D 그대로입니다.
- WebGL을 쓸 수 없거나 3D 그리기에 실패하면 자동으로 2D 화면으로 돌아갑니다. 느린 기기에서는 3D 해상도를 스스로 낮춥니다.

### 픽셀 그림

- 배치는 320×180칸 격자, 그림은 그 두 배인 **640×360 고해상도**로 그립니다.
- 픽셀 그림은 저해상도로 그린 뒤 Scale2x(EPX)로 두 배 키워 대각선 계단을 다듬고, 룰루의 눈·입·머리결, 설탕 코팅의 윤기, 구두 광택 같은 세부는 고해상도로 덧그립니다.
- 게임 화면은 창 크기에 맞춰 커지고, **전체 화면** 단추나 `F` 키로 화면을 꽉 채울 수 있습니다.

## 놀거리

| 장소 | 하는 일 |
| --- | --- |
| 룰루네 탕후루 | 시청자 주문대로 재료를 꽂고(최대 5개), 설탕 시럽이 **150~160℃(하드 크랙)** 일 때 담가 유리알 코팅을 만든 뒤, 룰루의 먹방을 본다. 주문 일치·코팅 품질에 따라 코인과 구독자가 늘어난다. |
| 아이스크림 뽑기 | 20코인으로 집게를 움직여 아이스크림 6종을 모은다. 도감을 채우면 사탕 왕관을 받는다. |
| 드롭타워 | 80m에서 떨어지며 탕후루를 받아 먹는다. 별은 보너스, 고추는 매워서 느려지고, 새는 콤보를 끊는다. |
| 룰루 옷장 | 옷 6벌, 머리 모양 4가지, 머리띠 6가지를 사서 입힌다. |

구독자가 늘면 새 재료가 열립니다: 블루베리(20) · 키위(50) · 마시멜로(100) · 젤리곰(180) · 고추(300).

## 소리

모두 WebAudio로 실시간 합성합니다 (음원 파일 없음). 브라우저 정책상 화면을 한 번 누르거나 키를 누른 뒤부터 소리가 납니다.

**악기**: 8비트 펄스파에 더해 플루트, 종, 오르골, 마림바, 일렉트릭 피아노(FM 합성), 하프(플럭), 현악 패드, 금관, 톱니파 리드, 여러 베이스(트라이앵글·콘트라베이스·펄스·톱니)를 발진기 겹치기, FM, 필터 엔벌로프, 비브라토로 만듭니다. 드럼은 킥·스네어·박수·하이햇·셰이커·림·탐·심벌입니다.

**믹스**: 파트마다 좌우 위치가 다른 스테레오, 1.9초 홀 잔향, 곡 박자에 맞춘 점8분음표 메아리를 씁니다. 화음 진행을 적어 두면 패드·분산화음·반주·베이스 무늬를 자동으로 만들어 내어 성부가 매끄럽게 이어집니다.

| 장소·상황 | 배경음악 | 편성 |
| --- | --- | --- |
| 타이틀·룰루랜드 거리 | 밝은 C장조 (132 BPM, 16마디) | 펄스 리드, B파트 종소리, 현악, 분산화음, 베이스, 드럼 |
| 탕후루 가게 | 스윙하는 F장조 카페 음악 (100 BPM, 16마디) | 플루트, 일렉트릭 피아노, B파트 마림바, 워킹 콘트라베이스, 브러시풍 드럼 |
| 설탕 시럽 끓이기 | 째깍거리는 A단조 (148 BPM, 8마디) | 하프 리드, 현악, 16분 분산화음, 톱니 베이스, 림 째깍 |
| 아이스크림 뽑기 | 오락실풍 D장조 (152 BPM, 16마디) | 칩 리드, B파트 종소리, 분산화음, 펄스 베이스, 박수 |
| 드롭타워 낙하 | 질주하는 E단조 록 (172 BPM, 16마디) | 톱니 리드, 현악, B파트 금관, 옥타브 베이스, 탐 필인 |
| 룰루 옷장 | G장조 왈츠 (3/4, 96 BPM, 16마디) | 오르골, 하프 분산화음, B파트 플루트, 현악, 콘트라베이스 |

곡은 장면이 바뀔 때 부드럽게 넘어가고, 결과 징글(금관+종, 짧은 잔향)이 울릴 때는 잠시 작아집니다. 휴대폰·태블릿처럼 터치 화면에서는 장식 성부(빠른 분산화음, 종·금관 겹침)를 빼서 소리가 끊기지 않게 합니다.

효과음은 행동마다 다릅니다: 발소리, 가게 문 종소리, 새소리와 분수(가까이 가면 커짐), 재료 꽂는 소리(마시멜로·젤리곰은 따로), 주문과 맞으면 딩동, 온도가 오를수록 빨라지는 온도계 삐삐(150~160℃에서는 높은 두 음), 보글보글 끓는 시럽, 담글 때 치익, 설탕이 굳는 유리 소리, 재료별로 다른 와삭 소리와 씹는 소리, 고추 매운 소리, 집게 모터·덜컹·경품 떨어지는 소리, 드롭타워 체인 소리와 바람, 옷장 방울·옷 스치는 소리·계산대 소리 등.

`M`은 배경음악, `N`은 효과음을 따로 켜고 끕니다 (화면 오른쪽 위 아이콘으로도 가능). 브라우저 탭을 숨기면 소리가 멈춥니다.

## 조작

- 마우스·터치: 화면의 버튼과 가게를 누르면 돼요.
- 키보드: `←→` 걷기, `↑`/`Enter` 들어가기, `1`~`8` 재료 꽂기, `Space` 담그기·뽑기, `Esc` 랜드로, `M` 배경음악, `N` 효과음, `F` 전체 화면.

진행 기록은 브라우저 `localStorage`에만 저장됩니다.

## 파일

- `src/game.js` — 게임 전체 (배치 320×180 · 그림 640×360, 픽셀 스프라이트, WebAudio 칩튠 음악·효과음)
- `src/world3d.js` — three.js 3D 무대 (거리·타이틀·가게, 후처리)
- `src/page.html` — 게임을 감싸는 페이지 (3D 캔버스 위에 픽셀 UI 캔버스를 겹친다)
- `build.py` — 쓰인 글자만 남기도록 갈무리 글꼴을 잘라 넣고 `index.html`(완성본)과 `dist/page.html`(Artifact 게시용)을 만든다

```bash
pip install fonttools brotli
python3 build.py   # 글꼴과 three.js가 없으면 npm 레지스트리에서 받아 온다
```
