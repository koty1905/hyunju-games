# 룰루랜드 — 탕후루 먹방 픽셀 게임

모바일 게임 「탕후루의 달인」(Tanghulu Master)의 **룰루랜드**에서 캐릭터와 놀이 콘셉트를 빌려 온 팬 창작 픽셀 게임입니다.
그림은 모두 코드 안의 픽셀 문자열로 새로 그렸고, 외부 이미지는 쓰지 않습니다.

`index.html` 하나만 브라우저로 열면 바로 할 수 있어요 (글꼴까지 들어 있음, 약 200KB).

## 화면

- 배치는 320×180칸 격자, 그림은 그 두 배인 **640×360 고해상도**로 그립니다.
- 픽셀 그림은 저해상도로 그린 뒤 Scale2x(EPX)로 두 배 키워 대각선 계단을 다듬고, 룰루의 눈·입·머리결, 설탕 코팅의 윤기, 구두 광택 같은 세부는 고해상도로 덧그립니다. 젤리곰과 소리 아이콘은 처음부터 고해상도로 그렸습니다.
- 원·선·언덕·하늘·보도블록도 고해상도 격자에서 그려 더 매끄럽습니다. 작은 글씨는 갈무리14(고해상도 픽셀 글꼴)로 씁니다.
- 게임 화면은 창 크기에 맞춰 커지고, **전체 화면** 단추나 `F` 키로 화면을 꽉 채울 수 있습니다. 캔버스는 기기 픽셀 비율에 맞춰 짝수 배율로 그려 픽셀이 흐려지지 않습니다.

## 놀거리

| 장소 | 하는 일 |
| --- | --- |
| 룰루네 탕후루 | 시청자 주문대로 재료를 꽂고(최대 5개), 설탕 시럽이 **150~160℃(하드 크랙)** 일 때 담가 유리알 코팅을 만든 뒤, 룰루의 먹방을 본다. 주문 일치·코팅 품질에 따라 코인과 구독자가 늘어난다. |
| 아이스크림 뽑기 | 20코인으로 집게를 움직여 아이스크림 6종을 모은다. 도감을 채우면 사탕 왕관을 받는다. |
| 드롭타워 | 80m에서 떨어지며 탕후루를 받아 먹는다. 별은 보너스, 고추는 매워서 느려지고, 새는 콤보를 끊는다. |
| 룰루 옷장 | 옷 6벌, 머리 모양 4가지, 머리띠 6가지를 사서 입힌다. |

구독자가 늘면 새 재료가 열립니다: 블루베리(20) · 키위(50) · 마시멜로(100) · 젤리곰(180) · 고추(300).

## 소리

모두 WebAudio로 실시간 합성합니다 (음원 파일 없음). 브라우저 정책상 화면을 한 번 누르거나 키를 누른 뒤부터 소리가 납니다.

| 장소·상황 | 배경음악 |
| --- | --- |
| 타이틀·룰루랜드 거리 | 밝은 C장조 행진 (132 BPM) |
| 탕후루 가게 (꽂기·먹방) | 느긋한 F장조 (104 BPM) |
| 설탕 시럽 끓이기 | 긴장감 있는 A단조 (148 BPM) |
| 아이스크림 뽑기 | 오락실풍 D장조 (152 BPM) |
| 드롭타워 낙하 | 빠른 E단조 (172 BPM) |
| 룰루 옷장 | 오르골풍 G장조 왈츠 (3/4, 100 BPM) |

곡은 장면이 바뀔 때 부드럽게 넘어가고, 결과 징글이 울릴 때는 잠시 작아집니다.

효과음은 행동마다 다릅니다: 발소리, 가게 문 종소리, 새소리와 분수(가까이 가면 커짐), 재료 꽂는 소리(마시멜로·젤리곰은 따로), 주문과 맞으면 딩동, 온도가 오를수록 빨라지는 온도계 삐삐(150~160℃에서는 높은 두 음), 보글보글 끓는 시럽, 담글 때 치익, 설탕이 굳는 유리 소리, 재료별로 다른 와삭 소리와 씹는 소리, 고추 매운 소리, 집게 모터·덜컹·경품 떨어지는 소리, 드롭타워 체인 소리와 바람, 옷장 방울·옷 스치는 소리·계산대 소리 등.

`M`은 배경음악, `N`은 효과음을 따로 켜고 끕니다 (화면 오른쪽 위 아이콘으로도 가능). 브라우저 탭을 숨기면 소리가 멈춥니다.

## 조작

- 마우스·터치: 화면의 버튼과 가게를 누르면 돼요.
- 키보드: `←→` 걷기, `↑`/`Enter` 들어가기, `1`~`8` 재료 꽂기, `Space` 담그기·뽑기, `Esc` 랜드로, `M` 배경음악, `N` 효과음, `F` 전체 화면.

진행 기록은 브라우저 `localStorage`에만 저장됩니다.

## 파일

- `src/game.js` — 게임 전체 (배치 320×180 · 그림 640×360, 픽셀 스프라이트, WebAudio 칩튠 음악·효과음)
- `src/page.html` — 게임을 감싸는 페이지
- `build.py` — 쓰인 글자만 남기도록 갈무리 글꼴을 잘라 넣고 `index.html`(완성본)과 `dist/page.html`(Artifact 게시용)을 만든다

```bash
pip install fonttools brotli
python3 build.py   # 글꼴이 없으면 npm 레지스트리에서 galmuri 패키지를 받아 온다
```
