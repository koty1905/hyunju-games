# 퇴근 불가 — 리라네 근무표

> 아주 귀엽다. 근데 얘네 이래도 되나? 아, 서류까지 있네. 현주는 끝났다.

리라 세계관을 배경으로 한 조작이 간단한 픽셀 게임입니다. 갓파더는 퇴근하려 하지만, 리라들의 행정 체계는 그것을 끝까지 허락하지 않습니다.
그림은 모두 코드 안의 픽셀 격자 함수로 새로 그렸고, 외부 이미지는 쓰지 않습니다. `index.html` 하나만 브라우저로 열면 바로 할 수 있어요 (글꼴 포함 약 190KB, 인터넷 없이 돕니다).

## 줄거리

1. 18시 정각. 사람 모습의 갓파더가 가방을 챙기는 순간 버터 교반기 → 빨래 → 빵 반죽 → 치즈 휠 → 자수틀 → 허브 바구니 → 핑크 소금 도구가 차례로 "뿅" 하고 나타납니다.
2. 문으로 가면 **«SHIFT INCOMPLETE.»** 문지기 리라가 근무일지를 내밀고, 그것을 받아 드는 순간 갓파더는 거대 개미핥기가 됩니다 (**«CLASS CHANGE: ANTEATER.»**).
3. 업무를 모두 끝내고 다시 문으로 가면 **«NEW TASK UNLOCKED.»** — 근무일지 도장, 허브 재검수, 치즈 뒤집기, 선물 세트, 명찰 자수, 수녀복 빨래, 무염 버터, 내일 아침 빵 반죽, 퇴근 신청서 결재…… 새 업무가 풀릴 때마다 문 옆 「퇴근 전 확인사항」 게시판이 한 줄씩 늘어납니다.
4. 마지막 희망처럼 문이 살짝 열리지만, 결재가 났다며 퇴근 확인서가 들어옵니다. 발도장을 찍으면 서류가 뒤집혀 「내일 근무 확인서」가 되고, 자정 종이 울리며 **«TOMORROW'S SHIFT CONFIRMED.»**
5. 로지가 웃으며 귀를 팔랑거리고, 갓파더는 카메라를 죽은 눈으로 바라봅니다. 정산서의 선택지는 [내일 출근하기]뿐이고 [퇴근]은 잠겨 있습니다. 누르면 근무 일수가 하루 늘어납니다.

전체 17건 · 한 판 8~10분. 업무 하나에 시계가 20분씩 흘러 18:00에서 자정으로 갑니다. 기력은 업무마다 줄지만 1% 밑으로는 떨어지지 않습니다 (최소 근무 기력 규정).

| 빨래 짜서 널기 · 수녀복 빨래 | 시스터 리라 | 누르고 있다가 초록 칸에서 떼기 (너무 짜면 찢어짐) |

| 치즈 휠 정리 · 뒤집기 | 알프스 리라 | 반짝이는 칸 위에서 멈추기 |

| 허브 분류 · 재분류 | 로즈마리라 | 긴 주둥이가 맞는 바구니 위에 올 때 내려놓기 (틀리면 재분류 신청서) |
| 핑크 소금 소분 · 선물 세트 | 로지 | 연타로 빻고, 누르고 있다가 12g(30g)에서 떼기 |
| 근무일지 도장 받기 | 행정 리라 | 컨베이어의 네모 칸이 도장 밑에 올 때 |
| 퇴근 신청서 작성·결재 | 행정 리라 | 세 칸 채우고 다섯 단계 결재를 기다리기 (재촉하면 늦어짐) |
| 퇴근 확인서 서명 | 문지기 리라 | 누르고 있기 |

## 인물 그림 원칙

- **리라**: 작고(40cm) 크림색, 안쪽이 분홍인 귀, 짙은 갈색 털 코와 바느질한 세로 입선, 주황 테두리 눈, 큰 분홍 발바닥, 꼬리 없음. 귀는 따로 움직여 서 있을 때도 들썩입니다 (참조: 리라 인형 사진).
- **알프스 리라**: 빨간 멜빵 치마, 흰 블라우스와 앞치마, 치마 밑으로 발이 보입니다.
- **시스터 리라 · 세라피나**: 아이보리 수녀복과 삐뚤삐뚤한 손자수. 세라피나는 늘 엄숙합니다.
- **로즈마리라**: 마릴라풍의 목 높은 옛날 드레스, 자수정 브로치, 엄격한 눈썹.
- **로지**: 리라와 같은 크림색, 귀에 분홍 리본.
- **갓파더**: 복슬복슬한 거대 개미핥기 — 늘어진 깃발 꼬리, 가늘고 긴 주둥이, 목에서 등으로 가늘어지는 흰 테두리 검은 띠, 검은 손목 띠와 큰 발톱, 지친 눈.

## 조작

- 키보드: `← →` 걷기, `Space`(또는 `Enter`·`Z`) 일하기·퇴근하기, `M` 배경음악, `N` 효과음, `F` 전체 화면.
- 마우스·터치: 방을 누르면 그쪽으로 걷고, 소품이나 문을 누르면 가서 일합니다. 미니게임에서는 화면 아무 데나 누르면(누르고 있으면) 됩니다.

근무 일수와 소리 설정만 브라우저 `localStorage`에 저장됩니다.

## 소리

모두 WebAudio로 실시간 합성합니다. 배경음악은 한 선율(리라 근무가)을 장면마다 바꿔 씁니다: 방에서는 F장조 폴카(126 BPM, 움파 반주), 업무 중에는 빠른 판(156 BPM), 결재 대기에는 느린 엘리베이터 음악, 정산서에서는 오르골. 갓파더가 카메라를 볼 때는 음악이 멈춥니다.

## 파일

- `src/game.js` — 게임 전체 (배치 320×180 · 그림 640×360, 픽셀 격자 그림, 미니게임, 연출 스크립트, WebAudio)
- `src/page.html` — 게임을 감싸는 페이지
- `build.py` — 쓰인 글자만 남기도록 갈무리 글꼴을 잘라 넣고 `index.html`(완성본)과 `dist/page.html`(Artifact 게시용)을 만든다

```bash
pip install fonttools brotli
python3 build.py   # 글꼴이 없으면 npm 레지스트리에서 받아 온다
```
