# hyunju-games

Netlify 사이트 `hyunju-games`(https://hyunju-games.netlify.app)로 배포되는 게임 모음입니다.
빌드 단계 없이 저장소를 그대로 올리며, 첫 화면은 `index.html`(게임 목록)입니다.

## 고전 게임

- [block-stack](block-stack/) — 블록 쌓기
- [snake](snake/) — 뱀 게임
- [brick-breaker](brick-breaker/) — 벽돌 깨기
- [2048](2048/) — 2048
- [dino-run](dino-run/) — 공룡 달리기
- [frog-cross](frog-cross/) — 개구리 건너기

모두 외부 파일이 필요 없는 한 장짜리 HTML이며, 각 폴더의 `index.html`을 브라우저로 열면 바로 할 수 있습니다.

## 픽셀 게임

- [lulu-land](lulu-land/) — 룰루랜드: 탕후루 먹방 픽셀 게임
- [rira-shift](rira-shift/) — 퇴근 불가: 리라네 근무표 픽셀 게임
- [panda-clause](panda-clause/) — 판다 면제 조항: 러바오가 나오는 리라 에피소드 2 픽셀 애니메이션
- [panda-shift](panda-shift/) — 판다 면제 조항 게임판: 러바오가 VIP로 오는 토요일 근무 픽셀 게임

이 게임들은 원래 `koty1905/colab` 저장소에 있었으며, 수정 기록을 그대로 가지고 이 저장소로 옮겨 왔습니다.
