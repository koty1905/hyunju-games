# 판다 면제 조항 — 게임판 (리라네 근무표 · 토요일 VIP 편)

> 러바오는 누워도 근무 완료. 갓파더는 서류까지 먹혀도 근무 미완료.

애니메이션 「판다 면제 조항」을 「퇴근 불가」처럼 버튼 하나로 하는 게임으로 옮겼습니다. `index.html` 하나만 브라우저로 열면 됩니다 (글꼴 포함 약 200KB, 인터넷 없이 돕니다).

## 줄거리

1. 토요일 07:00. 「취급주의: 판다 · 위아래 없음」 상자가 도착하고 러바오가 나옵니다. **«VIP GUEST ARRIVED.»** 갓파더는 임명장을 받아 **«ROLE ASSIGNED: VIP MANAGER.»**
2. 러바오는 방 안을 돌아다니며 대나무를 먹다가, 틈만 나면 낮잠 매트에 누워 **«LE BAO: SHIFT COMPLETE.»**를 받습니다. 갓파더가 문으로 가면 **«SHIFT INCOMPLETE.»** — 바로 그 순간에도 러바오는 근무 완료입니다.
3. 업무를 끝내고 문으로 가면 **«NEW TASK UNLOCKED.»** 다섯 라운드, 열 가지 업무. 문 옆 「퇴근 전 확인사항」은 늘어나고, 첫 업무 뒤에는 벽에 「판다 면제 조항 제1조: 판다는 귀엽다.」가 붙습니다.
4. 노을이 지면 러바오가 대나무 한 줄기를 건네고, 로지는 ₩12,000 영수증을 건넵니다.
5. 17:00. 러바오는 스스로 뛰어 상자로 들어가 손을 흔들고 **«LE BAO: DAY OFF CONFIRMED.»** 갓파더에게는 **«TOMORROW'S SHIFT CONFIRMED.»**와 「러바오 정기 방문: 매주 토요일」. 로지가 귀를 팔랑이고, 갓파더는 죽은 눈으로 카메라를 봅니다. 정산서의 선택지는 [다음 주 토요일 출근]뿐입니다.

## 업무 (버튼 하나로)

| 라운드 | 업무 | 감독 | 조작 |
| --- | --- | --- | --- |
| 1 | 신입 등록 서류 받기 | 행정 리라 | 서류를 내밀면 러바오가 먹는다. 세 장째에 조항이 생긴다 |
| 1 | VIP 치수 재기 | 알프스 리라 | 누르고 있어 줄자를 감는다. 끝까지 감아도 모자라 "측정 불가" |
| 1 | 대나무 껍질 벗기기 | 로즈마리라 | 연타로 벗겨 다섯 줄기를 쌓는다. 러바오가 1.6초마다 한 줄기씩 먹는다 |
| 2 | 대나무 재고 보충 | 로즈마리라 | 러바오가 탄 수레를 연타로 민다. 멈추면 뒤로 굴러간다 |
| 2 | 굿즈 발도장 받기 | 로지 | 러바오가 발을 들 때 누른다. 헛치면 갓파더 얼굴에 찍힌다 |
| 2 | 사인회 줄 관리 | 문지기 리라 | 번호표 순서대로 들여보낸다. 틀리면 "새치기 적발!" |
| 3 | 낮잠 자리 청소 | 시스터 리라 | 빗자루 박자. 청소가 끝나면 러바오가 바로 눕는다 |
| 3 | 자는 러바오 포토존으로 모시기 | 로지 | 연타로 살살 민다. 가끔 뒤척이면 밀려난다 |
| 4 | 판다 면제 신청 | 행정 리라 | 판다처럼 눕기(누르고 있기) → «SHIFT INCOMPLETE.» → 눈에 검은 칠(타이밍) → 심사 0점 → 반려 |
| 5 | 노을과 대나무 한 줄기 | 로지 | 받기. 영수증이 따라온다 |

시계는 07:00에서 업무마다 55분씩 흘러 17:00에 끝납니다. 오른쪽 위에는 기력, 리라 매출, **러바오 근무 완료 횟수**(낮잠 횟수)가 나옵니다.

## 조작

- 키보드: `← →` 걷기, `Space`(또는 `Enter`·`Z`) 일하기·퇴근하기, `M` 배경음악, `N` 효과음, `F` 전체 화면.
- 마우스·터치: 방을 누르면 그쪽으로 걷고, 소품이나 문을 누르면 가서 일합니다. 미니게임에서는 화면 아무 데나 누르면(누르고 있으면) 됩니다.

토요일 주차와 소리 설정만 브라우저 `localStorage`에 저장됩니다.

## 파일

- `src/game.js` — 게임 (방·소품·러바오 행동·업무·미니게임·연출·그리기)
- `src/page.html` — 게임을 감싸는 페이지
- `build.py` — `../panda-clause/src/common.js`(리라·갓파더 그림과 소리, 「퇴근 불가」에서 옮겨 옴)와 `../panda-clause/src/panda.js`(러바오 그림과 소품) 뒤에 `src/game.js`를 이어 붙이고, 쓰인 글자만 남긴 갈무리 글꼴을 넣어 `index.html`과 `dist/page.html`을 만든다

```bash
pip install fonttools brotli
python3 build.py
```
