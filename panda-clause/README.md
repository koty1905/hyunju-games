# 판다 면제 조항 — 리라 에피소드 2

> 이 세계에서 노동을 면제받는 존재는 딱 하나다. 그게 갓파더는 아니다.

「퇴근 불가」의 다음 날, 리라네에 러바오가 VIP 손님으로 찾아오는 약 1분 40초짜리 픽셀 애니메이션입니다.
그림은 모두 코드 안의 픽셀 격자 함수로 새로 그렸고, 외부 이미지는 쓰지 않습니다. `index.html` 하나만 브라우저로 열면 됩니다 (글꼴 포함 약 140KB, 인터넷 없이 돕니다).

## 그림 원칙

- **러바오** (사진 참조): 둥글고 볼이 통통한 흰 얼굴, 아래 바깥으로 처진 검은 눈 패치 안의 갈색 눈, 까만 동그란 귀, 넓은 까만 코, 태연한 표정, 턱 아래 살짝 베이지빛 털, 가슴과 어깨를 두르는 검은 띠, 검은 팔다리와 발바닥 패드. 리라 < 갓파더 < 러바오 순으로 크다.
- **리라** (인형 사진 참조): 크림색 곱슬 털, 분홍 귀 안쪽, 짙은 갈색 털 코와 세로 입선, 주황 테두리 눈, 꼬리 없음. 앉으면 두 다리를 앞으로 뻗어 큰 분홍 발바닥이 정면으로 보인다. 로지는 분홍 리본.
- 갓파더와 다른 리라들은 「퇴근 불가」와 같은 그림을 쓴다.

## 조작

`Space` 재생·멈춤, `← →` 장면 이동, `R` 처음부터, `M` 소리, `F` 전체 화면. 화면을 누르면 재생·멈춤이고, 아래 단추로도 조작할 수 있습니다.

## 소리

WebAudio로 실시간 합성합니다. 리라네 폴카(「퇴근 불가」 테마), 러바오 테마(G장조 5음 음계에 목탁 같은 똑딱), 노을 장면의 느린 곡, 마지막의 오르골. 갓파더가 카메라를 볼 때는 음악이 멈춥니다.

## 파일

- `src/common.js` — 화면 맞추기, 색, 글꼴, 소리, 픽셀 격자, 리라·갓파더 그림 (「퇴근 불가」에서 가져와 앉은 자세를 더함)
- `src/scenes.js` — 러바오 그림, 소품, 방 배경, 장면 11개
- `src/engine.js` — 재생 진행, 처음·끝 화면, 입력
- `src/page.html` — 애니메이션을 감싸는 페이지
- `build.py` — 세 스크립트를 이어 붙이고, 쓰인 글자만 남긴 갈무리 글꼴을 넣어 `index.html`과 `dist/page.html`(Artifact 게시용)을 만든다

```bash
pip install fonttools brotli
python3 build.py
```
